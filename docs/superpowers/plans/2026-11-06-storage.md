# История и объём файлов

1. В расширенных настройках показать объём внутренних файлов и временного кэша приложения.
2. Добавить очистку истории с подтверждением: файлы в галерее остаются, список недавних и сведения о повторных загрузках очищаются.
3. Проверить подсчёт вложенных файлов тестами и собрать приложение без доступа к сети.
