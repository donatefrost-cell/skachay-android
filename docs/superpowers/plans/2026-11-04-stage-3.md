# YouTube: план

**Цель:** добавить обработку ссылок YouTube через yt-dlp, сохранив отдельный быстрый путь для прямых медиафайлов.

1. Проверить распознавание точных доменов `youtube.com` и `youtu.be`, включая допустимые поддомены и поддельные похожие домены.
2. Подключить `youtubedl-android` 0.18.1 и ffmpeg, заранее подготовить окружение в фоне и не запускать Python при прямой загрузке.
3. Запускать yt-dlp один раз на ссылку: одно видео, H.264/AAC до 720p при наличии, четыре потока фрагментов, без перекодирования и внедрения метаданных. Сохранять готовый файл тем же путём, что и прямые загрузки.
4. Не проверять обновление перед каждой загрузкой. При ошибке обновить движок и повторить один раз; фоновая ежедневная проверка не должна задерживать первое скачивание.
5. Собрать и запустить тесты. Видео YouTube и Shorts проверить на Android-устройстве; до этого не заявлять, что они скачиваются успешно.
