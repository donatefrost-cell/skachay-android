# Передача ссылок и сохранение: план

**Цель:** принимать ссылку из меню «Поделиться» и надёжно сохранять доступный по прямому URL файл в галерею.

**Интерфейсы:** `SharedUrl.firstIn(text: String?): String?` извлекает первую корректную HTTP(S)-ссылку; сервис загрузки получает URL через `Intent`, публикует результат после завершения и сообщает об ошибке в уведомлении. Дальнейшие обработчики социальных сетей будут передавать в загрузчик прямые адреса медиа и необходимые заголовки.

1. Написать тесты на первую ссылку в тексте, удаление конечной пунктуации, отсутствие допустимой ссылки и отклонение схем, отличных от HTTP(S). Запустить их и убедиться, что они выявляют отсутствующее поведение, затем реализовать и повторить проверку.
2. Настроить `ACTION_SEND` и `ACTION_VIEW` в отдельной прозрачной Activity, сделать `finish()` сразу после запуска сервиса. Ошибки запуска показывать понятным сообщением.
3. Добавить службу с каналом уведомлений, прогрессом, повтором и ограничением одновременно выполняемых загрузок. Проверить прямую загрузку локальным HTTP-сервером, включая сервер, который игнорирует Range.
4. Сохранять завершённое содержимое через MediaStore с `IS_PENDING` на API 29+ и через доступный путь с разрешением на API 26–28; незавершённые файлы удалять. Проверить получение и открытие URI, повтор и отказ в разрешении на телефоне или эмуляторе.
5. Запустить unit-тесты и `assembleDebug`; отдельно проверить фактическую установку и получение файла на устройстве. Отсутствие устройства указать в отчёте и инструкции ручной проверки.
