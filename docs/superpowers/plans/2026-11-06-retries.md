# Настройка повторов

1. Добавить настройку от 0 до 5 повторов для опытного режима с обычным значением 2.
2. Применять её к прямым загрузкам и сетевым запросам yt-dlp; отдельное обновление движка после ошибки оставить.
3. Проверить количество попыток на подставных HTTP-ответах без сети и проверить формирование параметров загрузчика.
