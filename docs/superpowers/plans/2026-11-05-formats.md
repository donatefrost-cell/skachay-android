# Предпросмотр и выбор формата YouTube

1. Извлекать сведения о видео один раз и хранить их в закрытом временном кэше с ограниченным сроком действия.
2. Показывать название, автора, длительность, обложку и фактически доступные видео- и аудиоформаты с разрешением, частотой кадров, кодеком и примерным размером, если сервис их сообщает.
3. Передавать выбор загрузчику и использовать сохранённый info JSON через `--load-info-json`, не выполняя повторное извлечение перед скачиванием.
4. Проверить обработку списка и безопасного идентификатора формата тестами и реальным открытым видео на эмуляторе. Остальные варианты выбора описать как незавершённые.
