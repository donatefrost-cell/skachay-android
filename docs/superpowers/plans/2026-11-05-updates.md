# Проверка и установка обновлений

1. Разбирать ответ GitHub Releases как данные: принимать только более новую стабильную версию с APK проекта и доверенным адресом; ограничивать размер ответа.
2. Проверять обновления при наличии сети приблизительно раз в сутки через WorkManager, сохранять найденную версию и предлагать ручную проверку в настройках.
3. Загружать APK во внутренний кэш приложения, проверять имя пакета, версию и подпись установленного приложения. После действия пользователя открыть системный установщик через FileProvider.
4. Проверить парсер, отказ на подмену, сетевой запрос на локальном сервере и экраны на эмуляторе. Доступность настоящего обновления отдельно зависит от публичности выпуска и наличия постоянного ключа.
