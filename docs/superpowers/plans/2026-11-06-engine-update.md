# Выбор канала и ручное обновление движка

1. Сохранять выбранный канал в настройках, по умолчанию использовать стабильный.
2. Применять выбранный канал при плановом и повторном обновлении после ошибки; не обновлять движок одновременно со скачиванием.
3. Добавить в расширенные настройки выбор канала и кнопку с понятным результатом обновления или ошибки.
4. Проверить сохранение настроек тестами и, если GitHub доступен с эмулятора, обновление на работающем Android.
