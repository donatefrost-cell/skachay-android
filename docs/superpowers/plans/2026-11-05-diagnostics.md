# Диагностика загрузок

1. Сохранять последнее состояние и последнюю понятную ошибку отдельно для YouTube, Instagram, TikTok и прямых ссылок, не записывая ссылки и cookies.
2. Измерять получение сведений, передачу данных, объединение и сохранение; если движок не сообщает стадию, показывать «нет данных».
3. Добавить в расширенные настройки экран диагностики с проверкой ссылки через обычный загрузчик и копированием обезличенного журнала.
4. Проверить измерение стадий тестами, собрать приложение и проверить экран и реальную загрузку на эмуляторе.
