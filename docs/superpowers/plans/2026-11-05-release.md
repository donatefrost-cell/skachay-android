# Подписанный выпуск

1. Получать версию выпуска из тега `v1.0` или `v1.0.1` и вычислять возрастающий Android versionCode.
2. При наличии четырёх переменных окружения подписывать release APK ключом владельца; при неполных данных завершать сборку с понятной ошибкой.
3. Добавить GitHub Actions для тегов: прочитать секреты, собрать и проверить APK, приложить его к GitHub Release. Не создавать реальный тег или постоянный ключ без действий владельца.
4. Проверить локально временным тестовым ключом, включая подпись и содержимое APK; описать владельцу безопасное создание и хранение собственного ключа, настройку секретов и установку APK.
