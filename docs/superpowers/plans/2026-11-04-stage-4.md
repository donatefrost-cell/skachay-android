# Instagram: план

**Цель:** получать прямые адреса публичных видео, фотографий и каруселей без входа в аккаунт.

1. Проверить извлечение shortcode только из поддерживаемых путей и безопасных доменов, удаление параметров отслеживания и обработку перенаправлений.
2. Тестами проверить распаковку встроенного JSON, порядок смешанной карусели и приоритет видео над его обложкой; отдельно проверить запасные метатеги Open Graph.
3. Сначала запрашивать публичный embed, затем страницу с альтернативными user agent. Передавать общему загрузчику адреса и необходимые заголовки. Когда данные отсутствуют, использовать уже подключённый yt-dlp и сообщать о неудаче простым текстом.
4. Сохранить каждый найденный элемент в галерею; проверить отсутствие повторной загрузки завершённого поста.
5. Запустить тесты и сборку. Проверить общедоступные reel, фотографию и карусель на устройстве; ограничения доступа Instagram отразить в отчёте.
