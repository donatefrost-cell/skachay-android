# Проверка открытого выпуска

1. Проверить доступность опубликованных правил и последнего выпуска без входа в GitHub с Android-эмулятора.
2. Проверить, что обновление скачивается, имеет нужную подпись и открывает системный установщик.
3. Сохранить ключ подписи вне Git и подтвердить, что опубликованный APK совместим с ARM-телефонами.
