# Устойчивость прямых загрузок

1. Если сервер отклоняет проверку диапазонов, попробовать обычную загрузку целого файла.
2. При ошибке получения прямой ссылки показывать ошибку; запускать общий обработчик видео только после успешного получения страницы вместо медиа.
3. Проверить разные ответы локального HTTP-сервера, отсутствие повторного запроса обработчиком и живую прямую ссылку; затем собрать APK и проверить CI.
