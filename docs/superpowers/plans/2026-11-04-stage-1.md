# Первый этап приложения «Скачай»: план

> Выполнение: последовательно, с проверкой результата перед переходом к следующему этапу.

**Цель:** создать минимальный Android-проект, который открывается и собирается локально и в GitHub Actions.

**Архитектура:** один модуль Android с Kotlin и Compose. Экран на этом этапе не предлагает неработающие действия. Общая архитектура описана в `docs/superpowers/specs/2026-11-04-skachay-design.md`.

**Технологии:** Android API 26–37, Material 3, Gradle Wrapper, GitHub Actions.

## Проверки

- [x] Сформировать Gradle Wrapper фиксированной версии.
- [x] Выполнить `./gradlew testDebugUnitTest assembleDebug` и убедиться, что создан APK.
- [ ] Загрузить проект в отдельный репозиторий и проверить результат GitHub Actions.
- [ ] Следующий этап начинать после успешной проверки сборки.
