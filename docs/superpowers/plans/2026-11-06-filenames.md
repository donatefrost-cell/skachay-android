# Имя сохраняемого файла

1. Добавить в экран выбора необязательное имя; расширение определять по фактическому типу файла.
2. Убирать опасные символы и ограничивать длину имени, нумеровать несколько элементов публикации.
3. Не перезаписывать одноимённые файлы на старых Android; сохранять имя при повторной попытке.
4. Проверить обработку имён, совпадения и сохранение через MediaStore, затем проверить реальную загрузку на эмуляторе.
