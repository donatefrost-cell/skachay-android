# TikTok: план

**Цель:** извлекать видео и все изображения фото-публикации без обязательного входа.

1. Проверить извлечение нужной публикации по ID из `__UNIVERSAL_DATA_FOR_REHYDRATION__` и `SIGI_STATE`, не принимая аватары и рекомендованные ролики за результат.
2. Проверить порядок фото и приоритет видео без водяного знака. Разбирать ссылки и короткие перенаправления только на допустимых доменах.
3. Получать страницу с мобильным user agent и передавать CDN необходимые заголовки и временные cookies; не сохранять их между запусками.
4. При отсутствии прямого видео использовать yt-dlp. Если публикация содержит только фото, не сохранять вместо них аудиодорожку как успешный результат.
5. Выполнить локальные тесты и сборку, затем отдельно проверить публичные видео и фото-публикацию на Android.
