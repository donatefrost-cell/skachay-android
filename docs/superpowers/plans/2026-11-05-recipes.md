# Обновляемые данные обработчиков

1. Держать исходные правила в `recipe-defaults/recipes.json` и включить этот файл в APK как запасной вариант.
2. Проверять версию схемы, размеры строк и массивов, адреса сервисов и регулярные выражения; применять выражения линейным движком RE2/J. Отклонять весь некорректный файл.
3. Использовать правила в обработчиках Instagram и TikTok, включая выбор включённых стратегий, пользовательские агенты, шаблоны адресов, поля и шаблоны ссылок.
4. Сохранять только проверенные данные и раз в сутки запрашивать файл через WorkManager при наличии сети; не выполнять загруженный код.
5. Проверить разбор и отказ на ошибочных данных тестами, а также собрать и проверить приложение. В закрытом репозитории анонимный raw URL не работает — этот предел явно указать в README.
