# Итоги проверки безопасности

## Что исправлено

- Общие ссылки проходят ограниченную проверку схемы, длины, учётных данных, порта и домена. DNS-запросы через OkHttp отклоняют частные и специальные IP-адреса; редиректы проверяются, ограничены пятью переходами и для платформенных запросов ведут только на разрешённые домены.
- Ссылки на CDN проверяются перед скачиванием. Для YouTube разрешены `googlevideo.com`, для Instagram и TikTok — домены их CDN с проверкой границы поддомена.
- HTML/JSON, заголовки и кэш имеют ограничения размера. Видео и аудио передаются потоково во временные файлы; сетевые повторы и параллельные части ограничены.
- Имя файла очищается от управляющих символов, bidi-форматирования и опасных разделителей, ограничено по UTF-8, учитывает зарезервированные имена. При сбое убираются временные файлы и незавершённые записи галереи.
- Заголовки форматов очищены по списку разрешённых; Cookie не попадает в кэш социальных предпросмотров. В приложении нет WebView-входа Instagram и постоянного хранения Instagram-cookie.
- Диагностика скрывает URL, токены и значения cookie/authorization, хранит короткий журнал и безопасную запись необработанного падения.
- Проверка обновления ограничена GitHub API и APK-ресурсом GitHub Releases, сверяет SHA-256, пакет, версию и сертификат подписи, не ставит APK без действия пользователя.
- Для рецептов добавлены HTTPS, фиксированный адрес, ограничение 64 КиБ, проверка схемы и регулярные выражения RE2/J.
- Обновлены старые транзитивные Jackson, Commons Compress и Commons IO из библиотеки yt-dlp; их версии закреплены через BOM/прямые ограничения и включены в lockfile для сканирования OSV.
- Устранены уязвимые транзитивные версии из инструментов сборки и lint: Logback 1.5.34, Guava 33.7.2-jre, Commons Lang 3.18.0, HttpClient 4.5.13 и Bouncy Castle 1.85. Версии закреплены для всех конфигураций, а полная карта зависимостей записана в lockfile.
- Выключены незашифрованные запросы и резервное копирование. Сервис загрузки закрыт для внешнего запуска; PendingIntent неизменяемы; отказ уведомлений обрабатывается; очередь Room восстанавливает прерванные задания.
- В CI добавлены Android Lint, KtLint, OSV-Scanner, Gitleaks, Dependabot и закрепление GitHub Actions по SHA.

## Что осталось ограничением

- Встроенный yt-dlp работает вне OkHttp, но запускается через локальный HTTPS CONNECT-прокси. Прокси проверяет допустимые домены платформы/CDN и публичность IP для каждого нового соединения, подключается прямо к проверенному IP и не перехватывает TLS. Поэтому переход на другой хост повторно проверяется; число редиректов на том же хосте внутри зашифрованного соединения ограничить нельзя. Лимит пяти редиректов действует для OkHttp-запросов.
- Обновление `recipes.json` ещё не подписывается Ed25519. Сейчас подлинность ограничивают HTTPS и фиксированный путь репозитория.
- Вход с Instagram и постоянные cookie не реализованы. Временная сессия TikTok остаётся в памяти и удаляется вместе с процессом; cookie-заголовки не записываются в кэш.
- Полная ручная проверка на физическом телефоне остаётся необходимой для переключения сети, авиарежима, нехватки памяти, аварийного завершения, отмены загрузки и поведения установщика на разных версиях Android.

## CI-проверки

Перед выпуском CI должен подтвердить сборку debug/release, unit-тесты, screenshot previews, эмуляторные проверки очереди и уведомлений, Android Lint, KtLint, сканирование зависимостей и секретов. Сгенерированные снимки нужно отдельно визуально просмотреть; генерация PNG сама по себе не доказывает отсутствие обрезанного текста.
