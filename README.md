# Скачай

Android-приложение для сохранения медиа из ссылок. Сейчас проект находится на первом этапе: готовится основа приложения и автоматическая сборка. Загрузка видео и фото пока не реализована.

## Сборка

Потребуются JDK 21 и Android SDK с платформой API 37. В корне проекта выполните:

```sh
./gradlew testDebugUnitTest assembleDebug
```

На Windows вместо `./gradlew` используйте `gradlew.bat`. Готовый тестовый APK появится в `app/build/outputs/apk/debug/`. Его можно установить на телефон с Android 8 или новее. На этом этапе экран только сообщает, что приложение разрабатывается.

После отправки проекта в GitHub сборка будет запускаться автоматически; APK появится на странице запуска в разделе **Artifacts**.
