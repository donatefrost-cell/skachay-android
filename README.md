# Скачай

Android-приложение для сохранения медиа из ссылок. Проект находится в разработке: настроены сборка, приём ссылок, прямые загрузки, обработчики YouTube, Instagram и TikTok, главный экран и часть настроек.

## Сборка

Потребуются JDK 21 и Android SDK с платформой API 37. В корне проекта выполните:

```sh
./gradlew testDebugUnitTest assembleDebug
```

На Windows вместо `./gradlew` используйте `gradlew.bat`. Готовый тестовый APK появится в `app/build/outputs/apk/debug/`. Его можно установить на телефон с Android 8 или новее.

После отправки проекта в GitHub сборка будет запускаться автоматически; APK появится на странице запуска в разделе **Artifacts**.

## Как проверить текущий этап на телефоне

На Android-эмуляторе проверены: прямая ссылка на фотографию, видео YouTube, Instagram Reel, фотография и карусель из пяти изображений Instagram, видео и слайдшоу из трёх фотографий TikTok. На реальном телефоне приложение ещё не проверялось.

Также на эмуляторе проверены первый запуск, сохранение настроек после перезапуска, экран выбора при отправке ссылки и загрузка фотографии из него. Пока экран выбора предлагает только два пресета качества видео YouTube; предварительный просмотр и список реальных форматов ещё не готовы.

1. Установите тестовый APK и откройте «Скачай». Выберите «Просто» или «Для опытных». Разрешите уведомления, если хотите видеть результат. На Android 8–9 также разрешите доступ к памяти.
2. Откройте в браузере [тестовое изображение](https://upload.wikimedia.org/wikipedia/commons/a/a9/Example.jpg). В меню браузера нажмите «Поделиться» и выберите «Скачай».
3. Дождитесь уведомления «Готово», нажмите на него и проверьте изображение в галерее, в папке «Скачай».
4. Повторите отправку той же ссылки и проверьте уведомление «Уже скачано».

Дополнительно откройте общедоступную публикацию в соответствующем приложении и проверьте через «Поделиться» → «Скачай»:

- видео YouTube и Shorts;
- Instagram Reel, фотографию и карусель;
- видео и фото-слайдшоу TikTok.

Доступность конкретной публикации зависит от ограничений сервиса. Если Instagram не отдаёт исходный файл, запасной вариант может сохранить изображение меньшего разрешения: в одном тесте получена фотография 640×640. При ошибке yt-dlp пробует обновиться и повторить загрузку один раз.

В настройках уже можно выбрать качество видео YouTube (до 720p или до 1080p). В режиме «Для опытных» доступны способ обработки отправленных ссылок, число одновременных загрузок и соединений. При возврате в режим «Просто» снова включаются фоновая загрузка и стандартные значения. Остальные расширенные настройки ещё разрабатываются.

При временных ошибках прямой загрузки приложение повторяет запрос с увеличением паузы. Если сервер поддерживает диапазоны и позволяет проверить версию файла, оборванный диапазон продолжается с полученного места в рамках текущей загрузки. Возобновление после полного завершения процесса приложения ещё не реализовано. На этом этапе уведомление об ошибке может появиться для обычной веб-страницы вместо прямой ссылки на файл.
